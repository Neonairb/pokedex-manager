# Pokémon type icons

These SVG icons come from
[`duiker101/pokemon-type-svg-icons`](https://github.com/duiker101/pokemon-type-svg-icons).
The source README describes them as “for any use” and credits the original
visual design to Maxime Cypers.

The files are stored locally so the application does not require a third-party
network request to render Pokémon type labels.
